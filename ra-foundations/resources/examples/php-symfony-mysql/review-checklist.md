# Review checklist

<!-- Example profile taken from a Symfony 7.4 + MySQL wallet API. -->

- Every query uses PDO prepared statements: no user input concatenated into SQL.
- A use case that reads and then writes the same aggregate locks it (`SELECT ... FOR UPDATE`) inside the transaction.
- Writes that move money or create resources honour the `Idempotency-Key` header.
- Money is integer cents in a value object, never `float`.
- Identifiers are UUIDv7 generated by the controller; dates are UTC.
- Migrations are plain SQL classes in `migrations/`, applied to the application and test databases.
- Wiring lives in `config/services.yaml`; application code has no framework attributes.
